# Documentação do site DAFA

Site portfólio da **DAFA — Gerenciamento de Conteúdo** (Santo Antônio da Platina – PR).

## Onde está cada coisa

| Pasta | Para que serve | Abra quando… |
|---|---|---|
| [`prd/`](prd/00-README.md) | Documento de requisitos do produto: o quê e por quê | precisar entender objetivos, escopo e regras de cada seção |
| [`codebase/`](codebase/README.md) | Como o código funciona hoje | for mexer no código, na mídia ou no SEO |
| [`decisoes/`](decisoes/README.md) | Registros de decisões técnicas (ADRs) | quiser saber por que algo foi feito de um jeito |

## Ordem de leitura recomendada

1. `prd/01-visao-e-contexto.md`
2. `prd/06-arquitetura-da-informacao.md`
3. `codebase/arquitetura.md`
4. `codebase/modelo-de-conteudo.md`
5. Requisito da seção que você vai alterar (`prd/requisitos-funcionais/`)

Para só trocar texto ou adicionar projeto, vá direto em [`../COMO-ATUALIZAR.md`](../COMO-ATUALIZAR.md).
