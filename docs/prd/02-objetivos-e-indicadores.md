# 02 · Objetivos e indicadores

## Objetivos

| # | Objetivo | Ação esperada |
|---|---|---|
| O1 | Gerar conversas comerciais | Clique em **“Fale com a DAFA”** ou **“Solicite um orçamento”** (abre o WhatsApp) |
| O2 | Mostrar a qualidade do trabalho | Visitante assiste a pelo menos um projeto do portfólio |
| O3 | Ser encontrado em buscas locais | Aparecer para buscas como “produção de vídeo Santo Antônio da Platina” |
| O4 | Facilitar a atualização | A DAFA adiciona projetos sem depender de alteração de código |

## Indicadores (como medir)

Nenhuma meta numérica foi definida pela DAFA. Este PRD **não inventa números**; define apenas o que medir quando houver ferramenta de análise:

| Indicador | Objetivo | Fonte sugerida |
|---|---|---|
| Cliques nos links do WhatsApp | O1 | Evento de clique (ferramenta de analytics a definir) |
| Aberturas do modal de vídeo | O2 | Evento de clique nos cards do portfólio |
| Impressões e cliques em buscas locais | O3 | Google Search Console |
| Tempo para publicar um projeto novo | O4 | Relato da DAFA |

> Status: **não há analytics instalado** no site hoje. Ver [pendências](10-pendencias.md).
