# 12 · Glossário

| Termo | Significado |
|---|---|
| **Hero** | Primeira tela do site, com o título principal |
| **Showreel** | Vídeo de apresentação da DAFA logo após o hero |
| **Prévia** | Trecho de ~6 s, sem som, que toca sozinho no card do portfólio |
| **Pôster / capa** | Imagem exibida antes do vídeo carregar |
| **Modal** | Janela sobre a página onde o vídeo toca com som |
| **Scroll-scrub** | Animação cujo progresso acompanha a rolagem |
| **Pin** | Seção que fica parada na tela enquanto a animação avança |
| **Sequência de frames** | Imagens de um vídeo desenhadas em `<canvas>` conforme o scroll |
| **Bento** | Grade de cards de tamanhos diferentes (seção “Como funciona”) |
| **Cartão SD** | Cartão de memória desenhado com a marca DAFA, peça central dos serviços |
| **CTA** | Chamada para ação (“Solicite um orçamento”) |
| **Movimento reduzido** | Preferência do sistema (`prefers-reduced-motion`) para menos animação |
| **JSON-LD** | Dados estruturados que explicam o negócio ao Google |
| **Open Graph** | Metadados da prévia do link no WhatsApp e redes sociais |
| **Lenis** | Biblioteca de rolagem suave |
| **GSAP / ScrollTrigger** | Biblioteca de animação e seu plugin de animação por scroll |
